# STM32_FreeRTOS_EnvMonitor
项目描述：在STM32F103硬件平台上引入FreeRTOS实时操作系统重构裸机架构，集成I2C传感器与LCD屏幕，开发具备高并发能力的环境状态监测与软硬件交互系统。
•	项目功能： 独立编写SHT20温湿度传感器与TFT-LCD底层驱动。基于FreeRTOS 划分数据采集、UI渲染与心跳监控等独立任务，实现了物理环境数据的实时精准采集与本地彩色屏可视化展现。
•	架构优化： 针对传感器85ms的模数转换耗时，优化互斥锁（Mutex）管理，在转换期间主动释放I2C总线，大幅提升系统并发效率。针对初始化阶段死锁问题，利用ARM内核DWT硬件计时器重构微妙级延时，剥离对系统滴答定时器（SysTick）的依赖。
•	性能优化：针对sprintf庞大的内存开销与任务栈溢出隐患，编写轻量级浮点数转换算法，将核心任务堆栈消耗缩减超50%。结合LCD显存覆盖特性优化驱动层，实现了数据的无闪烁平滑刷新。
